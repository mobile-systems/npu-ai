### ✅ Рабочий вариант без сборки: `openvino_llm` от Intel
Это официальный пакет Intel, поддерживает GGUF напрямую, автоматически распределяет слои между CPU/NPU/ISP и не требует компиляции C-кода.

#### 1. Установка (Python 3.9+)
```powershell
pip install openvino_llm
```
> ⚠️ На Windows пакет автоматически скачает совместимые версии OpenVINO runtime. На Linux может потребоваться установка `libopenvino-dev` и драйверов NPU через  `intel-opencl` или `intel-gpu-driver`.

#### 2. Подготовка модели
`openvino_llm` работает с GGUF. Если ваша модель в другом формате, конвертируйте её:
```powershell
pip install gguf
gguf-converter your_model.bin your_model.gguf
```
Рекомендуемые квантования для NPU: `Q4_K_M`, `Q8_0`, `FP16`.

#### 3. Запуск (CLI)
```powershell
python -m ov.llm.cli --model ваш_модель.gguf --device NPU --max-seq-len 2048
```
Для интерактивного режима:
```powershell
python -m ov.llm.cli --model ваш_модель.gguf --device NPU --interactive
```

#### 4. Проверка работы NPU
В выводе CLI вы увидите:
```
INFO: OpenVINO LLM backend initialized
INFO: NPU device detected
INFO: Offloaded X layers to NPU, Y layers to CPU
```
Загрузку NPU можно отследить через **Диспетчер задач → Производительность → NPU** или `intel_gpu_top`.
